# coddy brand assets

Hermit, a hermit crab. A hermit crab claims one shell and lives in exactly one,
and two crabs never share a shell: that is coddy's rule for issues and worktrees.

| File | Use |
| --- | --- |
| `coddy.svg` | Mascot on a transparent background (README, docs) |
| `coddy-icon.svg` | App icon: mascot on a navy rounded tile |
| `icon/coddy-<size>.png` | Icon rasters at 16, 32, 64, 128, 256 and 512 px |
| `coddy-social.png` | 1280×640 GitHub social preview (Settings → Social preview) |

Colours: navy `#1B2A4A`, shell `#FFC857` / `#F4A93B`, crab `#FF7A59`.
